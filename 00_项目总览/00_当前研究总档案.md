# 当前研究总档案

更新日期：2026-08-28

状态：`V3_FORMAL_PROMOTION_GO`

## 1. 论文做什么

使用3层×64宽度的 SiLU 参数条件 MLP，无标签学习两个低能复值方向，求解二维周期参数化
Bloch–Schrödinger 本征 PDE 的最低 rank-2 谱投影。推理时，势函数 Fourier 尾能量决定
使用 tie-closed Fourier 空间还是 neural–Fourier 混合空间，最后通过成对正交化和 Hermitian
Rayleigh–Ritz 得到谱簇。

它属于真实的神经网络 PDE 本征求解器，但不是普通 residual PINN。

## 2. 正式实验

- 160个物理点；
- harmonic/Gaussian 两个势族；
- IID、exact、near、strict-OOD、gap-scan 五种区域；
- 3个封存 checkpoint seeds；
- 11种方法与消融；
- 共5,280行，身份无缺失、无重复；
- 单张 NVIDIA A10、CUDA 12.8；
- formal 与 convergence gates 全部通过。

主结果：SR-SC-NARR `0.030929`，kinetic Fourier-25 `0.043425`，rank-37 shell-3
`0.030799`。相对 Fourier-25 改善28.76%，bootstrap 95%区间 `[28.08%,29.44%]`。

## 3. 必须限制的论文主张

80个 harmonic 点全部走 Fourier，与 Fourier-25 完全一致；80个 Gaussian 点全部走 hybrid，
误差降低31.75%。因此论文主张是“对谱复杂势函数的条件性神经增强”，不是“神经方法在所有
势族上普遍更好”。formal 中路由与 family 完全混淆，阈值附近泛化尚未验证。

相对 rank-37 shell-3，本文 projector error 高0.42%，但 eigenvalue MAE 低12.75%、延迟低
19.84%、rank低10–12维，应写成 Pareto trade-off。

## 4. 发表判断

- SCI 四区：已具备正式投稿准备基础；
- SCI 三区：可以冲，但 roughness routing 的外部有效性仍弱；
