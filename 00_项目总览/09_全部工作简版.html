方法怎么工作

1 输入位置、Bloch 波矢、势函数参数
2 神经粗解无标签 trace 目标学习两个复值周期函数
3 解析校正加入完整二阶六角 Fourier shell
4 最终解在约21维空间中做 Rayleigh–Ritz

为什么不逐条预测能带：Dirac 交叉处两条带可以交换身份；学习整个 rank-2 谱簇不会受列顺序、复相位或簇内旋转影响。

创新点够不够

有论文价值的部分：交叉处不学单条能带，而学基底不变谱簇；神经参数方向与闭合 Fourier 壳层互补；对试验向量和 Hamiltonian 作用同步正交化；用同秩 Fourier-only 对照证明提升不是单纯增加模式。

已有相似工作：Wang–Xie 已做 trace 多本征对，Dai 已做 neural-subspace + Galerkin，Rowan 已做 Rayleigh quotient + Gram–Schmidt，Chang 已处理参数化重数与 mode switching。本文只能声称完整组合及其 crossing-aware 验证有差异，不能把每个传统零件写成首创。

最大审稿风险：组合创新可能被认为数学原创性有限；最近邻基线不是作者官方实现；速度对照是 GPU P2 对 CPU PWE；目前只覆盖两个势族和 rank-2。论文已主动写入这些限制。
