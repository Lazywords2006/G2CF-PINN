## 使用说明

### 快速下载命令

```bash
# 下载单个论文
curl -L -o "论文名.pdf" "https://arxiv.org/pdf/ARXIV_ID.pdf"

# 批量下载示例
for id in 2207.10289 2009.04544 2401.09876; do
    curl -L -o "paper_${id}.pdf" "https://arxiv.org/pdf/${id}.pdf"
done
```

1. 部分arXiv ID为示例性ID，实际下载前请在arxiv.org搜索确认
