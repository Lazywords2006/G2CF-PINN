## 📄 文献 1: DPINN - 不连续感知KAN-PINN

### 基本信息
| 项目 | 内容 |
|------|------|
| **标题** | Discontinuity-aware KAN-based physics-informed neural networks |
| **作者** | Guoqiang Lei, D. Exposito, Xuerui Mao |
| **arXiv** | 2507.08338 |
| **提交日期** | 2025年7月11日 (v1), 2026年3月24日 (v2) |
| **领域** | Computational Physics |

### 核心摘要
DPINN提出了一种不连续感知的KAN-based PINN框架，用于求解含激波的偏微分方程。

### 核心方法
1. **自适应傅里叶特征嵌入**: 将输入映射到高维傅里叶空间，捕获高频信息
2. **不连续感知网络**: 基于Kolmogorov表示定理推广，专门处理不连续性
3. **网格变换**: 动态调整网格以适应激波位置
4. **可学习人工粘性**: 自适应添加粘性项稳定激波

### 创新点
- ✅ 首次将KAN与傅里叶特征结合用于激波求解
- ✅ 可学习人工粘性，无需手动调参
- ✅ 不连续感知架构设计

### 实验结果
- 测试方程: 无粘Burgers方程、Riemann问题、超音速翼型流动
- 性能: 相比标准PINN显著提升激波捕获精度

### 与G2CF-PINN的关系
| 维度 | DPINN | G2CF-PINN (我们的) |
|------|-------|-------------------|
| 傅里叶特征 | ✅ | ✅ |
| 因果训练 | ❌ | ✅ |
| 梯度引导采样 | ❌ | ✅ |
| 人工粘性 | ✅ (可学习) | 可选 |

**结论**: **直接竞争者** - DPINN已使用傅里叶特征处理激波，但缺乏因果训练和梯度引导采样。

## 📄 文献 2: CI-PINN - 耦合积分PINN

### 基本信息
| 项目 | 内容 |
|------|------|
| **标题** | Coupled Integral PINN for Discontinuity |
| **作者** | Yeping Wang, Shihao Yang |
| **arXiv** | 2411.11276 |
| **提交日期** | 2024年11月18日 (v1), 2026年2月3日 (v2) |
| **领域** | Fluid Dynamics |

### 核心摘要
CI-PINN从积分守恒角度处理激波问题，借鉴有限体积法思想，通过耦合积分约束增强PINN的激波捕获能力。

### 核心方法
1. **标准PINN主网络**: 负责求解PDE
2. **辅助积分势网络**: 学习积分形式的解
3. **耦合积分约束**: 将微分形式转化为积分形式，自动满足守恒律
4. **有限体积法启发**: 借鉴FVM的积分守恒思想

### 创新点
- ✅ 首次将积分形式引入PINN框架
- ✅ 自动满足守恒律，无需额外约束
- ✅ 对激波位置不敏感

### 实验结果
- 测试方程: Burgers方程、Buckley-Leverett方程、Euler方程、浅水方程
- 性能: 在激波捕获和守恒性方面优于标准PINN

### 与G2CF-PINN的关系
| 维度 | CI-PINN | G2CF-PINN (我们的) |
|------|---------|-------------------|
| 傅里叶特征 | ❌ | ✅ |
| 因果训练 | ❌ | ✅ |
| 梯度引导采样 | ❌ | ✅ |
| 积分守恒 | ✅ | 可选 |

**结论**: **互补方向** - CI-PINN从积分形式处理激波，与我们的梯度引导方法思路不同，但可融合。

## 📄 文献 3: FastLSQ - 傅里叶特征精确解析导数

### 基本信息
| 项目 | 内容 |
|------|------|
| **标题** | FastLSQ: Solving PDEs in One Shot via Fourier Features with Exact Analytical Derivatives |
| **作者** | Antonin Sulc |
| **arXiv** | 2602.10541 |
| **提交日期** | 2026年2月11日 (v1), 2026年3月22日 (v4) |
| **领域** | Numerical Analysis |

### 核心摘要
FastLSQ提出使用三角随机傅里叶特征(TRFF)求解PDE，通过解析导数替代autodiff，实现超快速求解。

### 核心方法
1. **三角随机傅里叶特征(TRFF)**: 将输入映射到傅里叶空间
2. **解析导数**: 直接计算傅里叶特征的导数，无需autodiff
3. **最小二乘/Newton-Raphson**: 一次性求解，无需迭代训练
4. **多尺度特征**: 支持1-6维PDE

### 创新点
- ✅ 解析导数替代autodiff，速度提升100倍+
- ✅ 一次性求解，无需迭代训练
- ✅ 支持高维PDE (1-6维)
- ✅ 精度达到10^-7级别

### 实验结果
- 测试方程: 17个PDE (1-6维)
- 性能: 线性PDE 0.07秒达到10^-7精度
- 速度: 相比标准PINN提升100-1000倍

### 与G2CF-PINN的关系
| 维度 | FastLSQ | G2CF-PINN (我们的) |
|------|---------|-------------------|
| 傅里叶特征 | ✅ (TRFF) | ✅ |
| 解析导数 | ✅ | 可选 |
| 因果训练 | ❌ | ✅ |
| 梯度引导采样 | ❌ | ✅ |
| 迭代训练 | ❌ (一次性) | ✅ |

**结论**: **启发性** - FastLSQ的解析导数技术可借鉴用于加速G2CF-PINN的梯度计算。
