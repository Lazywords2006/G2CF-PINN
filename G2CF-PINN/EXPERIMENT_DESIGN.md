## 3. 详细实验设计

### 3.1 E1: Burgers方程基准测试

**目标**: 验证G2CF-PINN在标准基准问题上的性能

**实验设置**:
```
方程: ∂u/∂t + u·∂u/∂x = ν·∂²u/∂x²
初始条件: u(x,0) = -sin(πx)
边界条件: u(-1,t) = u(1,t) = 0
粘性系数: ν = 0.01/π
域: x ∈ [-1, 1], t ∈ [0, 1]
参考解: 高精度数值解（谱方法）
```

**对比方法**:
1. 标准PINN (Raissi et al., 2019)
2. PINN + 傅里叶特征 (无其他模块)
3. PINN + 因果训练
4. PINN + 梯度引导采样
5. G2CF-PINN (完整方法)

**评估指标**:
- 相对L2误差: ‖u_pred - u_ref‖₂ / ‖u_ref‖₂
- 激波位置误差: |x_shock_pred - x_shock_ref|
- 训练时间（墙钟时间）
- 收敛迭代次数

**采样配置**:
- 训练点: N_f = 10000 (域内), N_b = 100 (边界), N_0 = 100 (初始)
- 测试点: 10000 (均匀网格)
- 批大小: 全量训练

**代码模板**:
```python
# E1: Burgers方程基准测试

    'equation': 'burgers',
    'nu': 0.01/np.pi,
    'domain': {'x': [-1, 1], 't': [0, 1]},

}
```

### 3.6 E6: Euler方程（Sod激波管）

**目标**: 验证方法在复杂多激波问题上的能力

**实验设置**:
```
方程组:
∂ρ/∂t + ∂(ρu)/∂x = 0
∂(ρu)/∂t + ∂(ρu²+p)/∂x = 0
∂E/∂t + ∂((E+p)u)/∂x = 0

初始条件 (Sod激波管):
左状态: ρ=1, u=0, p=1 (x<0)
右状态: ρ=0.125, u=0, p=0.1 (x>0)

域: x ∈ [-1, 1], t ∈ [0, 0.5]
特点: 激波、接触间断、稀疏波共存
```

**参考解**: 精确Riemann解

### 7.3 效应量

```python
# Cohen's d
def cohens_d(group1, group2):
    n1, n2 = len(group1), len(group2)
    var1, var2 = np.var(group1, ddof=1), np.var(group2, ddof=1)
    pooled_std = np.sqrt(((n1-1)*var1 + (n2-1)*var2) / (n1+n2-2))
    return (np.mean(group1) - np.mean(group2)) / pooled_std
```
