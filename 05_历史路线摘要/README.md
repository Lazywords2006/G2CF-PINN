# 历史路线摘要

本目录保留已经停止路线的聚合结论、JSON/CSV 判定数据，以及
`BlockKyFan_旧阶段_20260729/` 工程快照。所有旧 Markdown 叙事文档已删除，避免它们与
当前 P5 结论冲突；需要恢复时使用 Git 提交 `ec850707`。

当前唯一研究主线是：`03_当前主线_BlockKyFanPINN/`。

## 为什么这些路线停止

| 历史路线 | 最终结论 | 用最直白的话解释 |
|---|---|---|
| EFA-TSONN | STOP | 三个候选训练全部停滞，没有形成可比较的有效结果。 |
| LLC-HFNO / deltaFNO | STOP | 三种子实验大多数门槛失败，OOD、物理一致性、训练时间和稳定性都没有证明优势。 |
| PeSDF-PINN | REVISE 后停止 | 只出现很小的局部改善，绝对精度没有过线，而且与近期奇异层 PINN 工作重叠较大。 |
| PeR-VPINN | STOP | 主方法没有超过最强 SUPG 代理，global/layer 误差约为 0.51/0.90，不能解释成有用解。 |
| G2CF-PINN | 停止作为论文主线 | 普通 PINN、傅里叶特征、因果训练和自适应采样的组合过于拥挤，难以形成足够强的新颖性。 |
| A-KyFanNet 1D | 只保留机制先导 | 30/30 训练和 13/13 门槛通过，说明“交叉处学习谱簇”可行；但一维问题和现有期刊工作重叠较大，不能单独支撑当前投稿。 |
| FalsifyPDE | 只保留方法教训 | 它帮助发现“PDE 残差很小但选错谱簇”的危险假阳性，因此当前主线必须用 projector error、外部谱隙和传统参考解共同评价。 |
| Block KyFan 低频 ROM / P5 | STOP 作为主创新 | near 区域有局部提升，但等算力 long-anchor 反超，gap-scan 又回退 6.47%，不能归因于低频结构。 |
