## 汇报结论

二维坐标空间 Block KyFan-PINN 的最小工程链路已经打通。模型确实使用自动微分求二维 Bloch-Schrodinger PDE 的本征函数，并以 Ky Fan 目标学习秩二谱簇。当前结果属于工程烟测，不属于论文主实验。

## 2026-07-11 Apple MPS 实测

配置：1个参数实例、96配点、2层×32宽、30步 Adam。

| 指标 | 实测值 | 烟测判断 |
|---|---:|---|
| Ky Fan 初始能量 | -0.0122192 | 仅作起点 |
| Ky Fan 最终能量 | -0.0237693 | 下降，PASS |
| 正交误差 | 1.19e-7 | PASS |
| projected residual RMS | 0.176853 | 可计算；精度未达标 |
| projector sine error | 0.248991 | 可计算；精度未达标 |
| 训练时间 | 0.51秒 | PASS |
| MPS内存 | 约3.38MB | PASS |

首次300步随机配点诊断出现“能量降低但投影误差恶化到0.4715”的数值伪优化。现已修复正交系数的空间导数耦合、改用随机平移周期网格、限定Dirac邻域，并用 `tanh` 将anchor correction限制为有界修正。

最终三种子MPS确认结果：平均 projector sine error 为 `0.317299±0.006385`；插值 `0.219078±0.008081`，对称谱簇 `0.311938±0.007515`，外推 `0.420881±0.003829`。三个种子均优于未训练anchor的 `0.371908`。600步延长检查均值约 `0.3096`，未出现重新漂移。因此本地算法pilot判定为GO，可以进入RTX CUDA smoke与pilot。
