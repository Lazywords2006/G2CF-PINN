# Block KyFan-PINN RTX 4090 CUDA 正式实验报告

## 1. 结论先行

本项目已完成真实二维神经 PDE 的 CUDA 主实验、基线、消融、敏感性、效率和参考解收敛审计。最终推荐方法为：

> **Optimized Block KyFan-PINN**：坐标空间周期 MLP + 秩二 free-electron anchor + 硬复 Gram-Schmidt + 无标签 Ky Fan trace，删除无实质收益的 residual 第二阶段。

最终 5 种子均值投影正弦误差为 **0.22372 ± 0.00117**，相对同预算 ordered-residual PINN 的 **0.72490 ± 0.01740** 下降 **69.14%**。这支持“精确内部简并时应学习固定秩谱簇，而不是强制追踪逐带标签”的核心主张。

## 3. PDE 与网络

求解二维参数化 Bloch–Schrödinger 本征 PDE：

`H_k u = [1/2(-i∇_s+k)^T G(-i∇_s+k)+V(s;V0,δ)]u = Eu`，

其中 `s∈[0,2π)^2`，`G=[[1,1/2],[1/2,1]]`，势函数为

`V=V0[cos(s1)+cos(s2)+cos(s1-s2)] + δ[sin(s1)-sin(s2)-sin(s1-s2)]`。

网络输入 `(s1,s2,k1,k2,V0,δ)`，输出两个复值周期 Bloch 函数。训练不使用预计算本征函数标签，目标是最低秩二谱子空间。

## 4. 实验公平性

主方法和 ordered PINN 共享：

- 正式种子 `[11,22,33]`；
- 5000 优化步；
- 1024 空间配点；
- 参数 batch=8；
- 4 个隐藏层，宽度 96；
- Adam，学习率 1e-3；
- 33×33 评价网格；
- plane-wave cutoff=8 参考解；
- 一致的插值、对称谱簇和外推案例。

独立确认使用未参与调参的种子 `[44,55]`。

| 方法 | 总体 projector error | 插值 | 对称谱簇 | 外推 | 训练总时间 | 峰值显存 |
|---|---:|---:|---:|---:|---:|---:|

| 独立确认 seeds 44/55 | 0.22455±0.00045 | 0.12092 | 0.19798 | 0.35474 | 339.0 s | 0.45 GiB |

合并 5 种子后，最终方法为 **0.22372±0.00117**。

## 6. 核心消融

| 消融 | projector error | 结论 |
|---|---:|---|
| 正确 anchor=0.1 + residual | 0.30117±0.00050 | 原始主方法 |
| 无 anchor | 0.29898±0.02781 | 均值略低，但方差大约 56 倍，外推恶化到0.48330 |
| 无 residual | 0.30117±0.00049 | residual 对投影精度无实质收益，应删除 |
| random 高频 anchor | 0.99449±0.00002 | 几乎完全失败 |
| wrong anchor | 0.59947±0.00981 | 错误低能先验显著损害结果 |

消融不支持“增加 residual 就是创新”；它支持的是：基不变谱簇目标是主要优势，正确 anchor 主要提供稳定性和外推正则。

## 8. 效率与参考解审计

- 参数量：29,188；
- 单个PDE参数在33×33空间网格上的GPU前向：1.017 ms均值，1.026 ms p95；这不是1089个参数查询；
- plane-wave cutoff=8 单个参数求解约 1.52 s（CPU）；
- cutoff=8 相对 cutoff=12 的谱簇投影差在三案例中均不超过 `1.5e-8`；
- cutoff=8 的前两本征值与 cutoff=12 的绝对差为 `1e-14` 量级；
- 因此正式评价的 cutoff=8 参考解已通过收敛核查。

不能宣称神经网络单次求解全面优于传统本征分解。可支持的主张是：训练后的参数化网络在大批量参数查询时具有摊销优势。

## 9. 成败判定

- 相对有序逐带 PINN：**明显有效**；
- 精确对称谱簇：**明显有效**；
- 多种子稳定性：**已满足**（最终 5 种子）；
- residual 校正：**不足以支持创新**，从最终方法删除；
- anchor 作用：**主要改善稳定性和外推**，但强度需要调节；
- 相对 no-anchor trace 的域内均值：没有绝对优势，必须如实报告；
- 与官方期刊代码的直接复现：尚未完成，ordered 和 no-anchor 是 `our implementation following ...`。

## 10. 投稿判断

1. 这是真实的坐标空间神经网络求二维 PDE 本征问题，不跑题。
2. 主实验已经达到 SCI 四区方向所需的基本实验完整度：传统参考解、强基线、三至五种子、消融、敏感性、外推、时间和显存均已有真实记录。
3. 创新强度评为 **中等**：核心在于对精确内部简并的基不变、固定秩、无标签参数化谱簇学习，不是 Ky Fan、anchor 或 Gram-Schmidt 单个组件首创。
4. SCI 四区：**有条件 GO**，但需要补齐论文叙事、官方基线或更强传统方法对照。
5. SCI 三区：**当前证据不够**；建议再增加第二种势族/算子、更强官方基线和谱隙理论。
