# 当前投稿判断（2026-08-24）

## 编辑结论

**Reject in present form / Encourage resubmission after method redesign.**

当前项目已经具备真实二维 PDE、可运行代码、权威证据和公平控制实验，但尚没有一个能
稳定优于强基线的核心新方法。P5 的科学结论是有效 STOP，而不是可以通过补几张图解决的
“小修”。

## 当前稿件能保留的内容

1. 二维 Bloch–Schrödinger rank-2 谱簇问题定义；
2. 为什么内部简并处应评价 projector / principal angle，而不是逐带编号；
3. 周期坐标网络、无标签 generalized trace 与硬正交化的实现底座；
4. P4/P5 受控实验与证据审计方法；
5. anchor 对稳定训练的重要性；
6. 低频 ROM 在 near 区域有局部收益、但机制归因和 gap 安全失败的负结果。

## 当前不能作为贡献的内容

- Ky Fan、trace、Gram–Schmidt、Grassmann、Bloch ROM 或 PWE fallback 本身；
- “低频结构比任意结构更有效”；高频控制没有形成足够强的结构归因；
- “候选优于等算力基线”；long-anchor 已经反超 near-cluster；
- “方法在整个参数域安全”；gap-scan 已回退 6.47%；
- “训练更久的 anchor 是新算法”；它只能是强基线；
- 任何 frozen-final、CUDA 5090 或量子几何神经结果，因为尚未运行。

## 最可能的审稿意见

1. 提升是否只是更多参数或训练时间？P5 已表明这是实质风险；
2. 为什么 gap-scan 退化，推理时如何检测？当前简单指标不足；
3. 与 Wang–Xie、Dai、Chang、Mian/Hsu 和传统 Bloch/PWE 的差异在哪里？
4. 为什么需要神经网络，而不是直接 PWE？必须报告 many-query break-even；
5. projector 预测是否带来实际物理价值？需要量子度量等下游任务，但不能预设结果；
6. 是否使用了真正独立的 final？目前没有，且不应提前打开。

## 投稿前硬门槛

新方法必须在统一数据、参数量和 wall-clock 预算下，同时满足：

- near-cluster 相对 long-anchor 改善至少 5%；
- gap-scan 不超过最佳非 ROM 基线 2%；
- 两个势族均改善，至少 5/6 势族×seed 配对获胜；
- 至少 3 个随机种子报告均值、标准差与配对统计；
- 风险排序显著好于随机，并报告 risk–coverage 与回退率；
- 与传统 PWE、anchor、long-anchor、Wang–Xie/trace 子空间及另一强神经基线公平比较；
- frozen final 只在 promotion GO 后运行一次并封存全部证据。

在这些条件满足前，不建议选择具体期刊或润色投稿摘要。
