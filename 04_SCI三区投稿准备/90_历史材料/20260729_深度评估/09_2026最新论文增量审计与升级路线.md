## 2. 最新论文改变了什么

### 2.1 最大的新威胁：Boundary-aware Neural Model Reduction

SIGGRAPH 2026 的 *Boundary-aware Neural Model Reduction for PDEs* 已经用一张无标签变分坐标网络跨形状与边界参数学习 PDE reduced bases，并覆盖 Dirichlet、Robin 与混合边界。它与 Shape Space Spectra 一起说明：

- “一张网络跨参数族做 eigenanalysis”不是新概念；
- “无标签变分训练”不是新概念；
- “连续参数到多个本征函数/基”不是新概念；
- 复杂边界也不适合作为本项目临时转向的低风险创新。

它仍未完整覆盖本文的核心对象：**二维 Bloch PDE、内部精确简并、固定秩 projector、参数相关低阶 Bloch ROM 作为 Grassmann chart、外部谱隙诊断与 chart fallback。**

### 2.2 NEO 与 ICLR Subspace Regression 已覆盖“本征空间学习”

- NEO（SIGGRAPH 2026）已经使用旋转不变 eigenspace、冗余 basis、质量感知算子与 Rayleigh–Ritz；
- Deep Learning for Subspace Regression（ICLR 2026）已经系统研究参数到 Grassmann 子空间的监督回归，并用高于目标秩的冗余空间改善平滑性与泛化；
- OMM（NeurIPS 2025）已经提供无需逐模态 deflation 的无序 block objective；
- Dai 等（CNSNS 2026）已经完成 neural trial subspace + Galerkin。

因此，“projector-first”“Grassmann”“冗余 rank”“block loss”与“Ritz refinement”都只能是组成部分或基线，不能写成首创。

### 2.3 Hybrid FNO 与拓扑能带学习提高了应用证据门槛

2026 年的 wave-vector explicit Hybrid FNO 已能从 FEM 标签预测声子晶体能带并跨分辨率泛化；ACS Photonics 的 KAN 工作已做拓扑能带分类与逆设计。这些工作不属于无标签 PDE eigensolver，但说明仅报告两条能带曲线和相对误差已经不够。

本文需要证明 fixed-rank projector 带来了逐带方法难以稳定提供的结果，例如：

- 简并附近的 cluster quantum metric；
- 非阿贝尔 Berry/Wilson-loop 量；
- projector 导数的稳定性；
- 与真实 many-query 任务相关的置信—精度—成本曲线。

### 2.4 最新自适应与函数空间论文限制了可宣称内容

npj Artificial Intelligence 2026 已给 residual-based adaptivity 建立统一变分解释；Nature Machine Intelligence 2026 强调神经架构到函数空间的坐标、求积权重和离散一致性。因此：

- “按残差重新采样”不能作为主要创新；
- 必须把采样限定为**谱簇特有的 gap–chart 联合难度准则**；
- 必须加入质量矩阵/求积权重与 33/65/129（必要时 257）分辨率一致性实验。

## 3. 哪些旧主张已经失效，哪些仍可保留

### 3.1 不能再写成贡献

1. 首次用神经网络求 PDE 本征问题；
2. 首次一张网络跨参数求多个本征函数；
3. 首次用 Ky Fan/trace 同时求多个本征态；
4. 首次用 eigenspace/Grassmann 解决符号或旋转歧义；
5. 首次处理 eigenvalue crossing 或 mode switching；
6. 首次做 neural subspace + Rayleigh–Ritz；
7. 首次使用物理 anchor、课程学习、主动采样或质量矩阵；
8. 只把 MLP 换为 KAN、FNO、Transformer 或注意力。

### 3.2 仍未发现完整同构的窄窗口

在本次公开正式文献检索中，尚未发现一种方法同时满足：

> 无 eigenspace 标签；单一参数坐标网络；二维 Bloch–Schrödinger PDE；在 exact internal degeneracy 处预测固定秩、基底不变谱 projector；以对称低阶 Bloch ROM 为局部 Grassmann chart；网络只学习度量正交补 correction；使用可计算的低阶 gap surrogate、block residual 与 chart angle 做可校准的 multi-chart routing 和数值 fallback。

这个“完整联合机制”才是当前论文剩余的创新空间。必须写“本次核验未发现完整同构”，不能写“世界首创”。

## 4. 推荐的新论文定位

### 4.1 暂定标题

**Label-Free Gap-Aware Multi-Chart Grassmann Correction for Internally Degenerate Bloch–Schrödinger Spectral Clusters**

中文：**面向内部简并 Bloch–Schrödinger 谱簇的无标签间隙感知多图册 Grassmann 神经校正方法**

### 4.2 不建议更换 PDE 与主网络类型

- 主 PDE 继续采用二维 Bloch–Schrödinger 本征偏微分方程；
- 网络继续采用轻量坐标 MLP/神经场，而非改成大模型；
- 输出继续采用 rank-2 projector/子空间，而非回到逐带编号；
- 训练继续使用方程与变分目标，不使用 eigenspace 标签。

原因：问题与硬件匹配，当前 smoke 已证明网络—PDE—projector 链路能工作。现在换 KAN/FNO/Transformer 只会增加与最新监督代理论文的重叠，不能自动增加创新。

### 4.3 方法升级为一个连贯机制

设参数为 \(\mu=(k,\xi)\)，目标秩为 \(r=2\)。

1. **参数相关低保真 chart**：用对称闭合的 3/9-wave PWE 或小 ROM 得到 \(A(\mu)\)；
2. **质量矩阵下的正交补 correction**：设 \(A^*MA=I\)，网络预测 \(N_\theta(\mu,s)\)，再构造

   \[
   Z_\theta=(I-AA^*M)N_\theta;
   \]

3. **度量感知 retraction**：在质量矩阵 \(M\) 下构造

   \[
   Q_\theta^* M Q_\theta=I,\qquad P_\theta=Q_\theta Q_\theta^*M;
   \]

4. **冗余 trial subspace 与 Ritz 选择**：令网络/校正空间维数 \(m=3\) 或 4，大于目标秩 \(r=2\)，在这个冗余空间内保留最低两个 Ritz 向量。若 \(m=r=2\)，Ritz 只旋转 frame、不会改善 projector，必须称为 **Ritz readout** 而不是 correction；
5. **多 chart 路由**：用 \(M\)-加权主角。当 \(\theta^M_{\max}(A,Q)\) 接近 \(90^\circ\) 时切换 3-wave/9-wave/邻域 chart；
6. **可计算的 gap–chart risk curriculum**：训练时不调用高 cutoff 真本征值或真 eigenspace，使用 block residual、低阶 ROM gap surrogate、chart disagreement 与 \(M\)-主角构造风险分数，例如：

   \[
   s(\mu)=
   w_1\frac{R_{block}(\mu)}{\widehat g^{ROM}_{ext}(\mu)+\varepsilon}
   +w_2\tan^2\theta^M_{max}(A,Q)
   +w_3D_{chart}(\mu);
   \]

7. **置信与 fallback**：高风险样本不强行输出，转为局部迭代校正或高 cutoff PWE，并报告 risk–coverage 曲线。高 cutoff 真 gap/真 projector 只用于冻结测试和离线校准，不进入常规训练。

注意：该分数是 **risk estimator**，不是严格 certificate。真实 Ky Fan excess 需要真低阶本征值和，真实外部 gap 需要第三本征值；若训练时调用高精度求解器，会削弱“label-free”主张。Grassmann retraction、Davis–Kahan 型界、Ritz 与主动采样本身也都不是新发明。贡献必须落在它们针对“无标签参数 Bloch 内部简并谱簇”的可计算统一设计和可证伪效果上。

## 5. 最值得增加的新内容：projector 特有的物理任务

最新 Berry/量子几何论文进一步说明，简并子空间应以 projector 或非阿贝尔连接处理。建议优先加入 cluster quantum metric：

\[
g_{ab}(k)=\frac{1}{2}\operatorname{Tr}\!\left[\partial_{k_a}P(k)\,\partial_{k_b}P(k)\right].
\]

可选再加入非阿贝尔曲率或闭合 Wilson-loop eigenphases。它们的价值是：逐个 eigenvector 在 exact degeneracy 附近可发生任意基旋转，而 projector、曲率迹/Chern form 与闭合 Wilson-loop 谱可构造为 gauge-invariant 量。Berry connection 本身 gauge-dependent，非阿贝尔曲率矩阵只 gauge-covariant，不能笼统称“所有 projector 导出量均 gauge invariant”。这些定义还要求 rank-2 cluster 与外部谱保持隔离。

### 已完成的低成本局部可行性探针（不是正式 reference validation）

已在 Apple CPU、本项目现有 float64 PWE solver 上运行，不涉及神经网络训练。检查 cutoff 4/6/8/10 与中心差分 \(\Delta k=0.02/0.01/0.005\)，原始数据见 `11_projector量子几何参考探针.csv`，配置、代码和输出哈希见 `11_projector量子几何参考探针.metadata.json`；可重跑脚本为 `scripts/probe_projector_quantum_geometry.py`。

| 势族 | cutoff / \(\Delta k\) | \(g_{xx}=g_{yy}\) | \(g_{xy}\) | 外部 gap | \(\operatorname{Tr}F_{xy}\) |
|---|---|---:|---:|---:|---:|
| harmonic | 10 / 0.005 | 1.711619790 | 0.855809894 | 0.3614872924 | 0 |
| localized Gaussian | 10 / 0.005 | 12.33365574 | 6.166708037 | 0.1144962330 | \(1.16\times10^{-12}\) |

数值判读：

- harmonic 在 cutoff 6/8/10 下给出相同量级与相同显示精度，信号稳定；
- Gaussian 从 cutoff 8 到 10 的 \(g_{xx}\) 相差约 0.22%，且 cutoff 10 下把 \(\Delta k\) 从 0.01 减半到 0.005 只改变约 0.30%，初步通过参考收敛探针；
- 两个势族的 cluster quantum metric 明显非零，说明它可以成为 projector-first 的下游评价；
- rank-2 总曲率迹在当前保持对称的设置下约为数值零，说明**不能预设非零总 Berry 曲率或 Chern 数**。

探针结论：**把 cluster quantum metric 纳入下一轮局部研究 = GO；总 Berry-curvature trace 作为当前主卖点 = STOP。** 下一阶段仍需先用 symmetry-closed Fourier shells 在 K 邻域/路径重做正式 reference validation，再比较神经 projector 导数能否重现该物理量。

当前探针的明确限制：现有 solver 使用方形 Cartesian cutoff，不保持 honeycomb K 点有限维旋转对称闭包；Gaussian 内部 gap 随 cutoff 非单调，仍有截断诱导伪劈裂。新归档已报告 \(\|P^2-P\|_F\)、Hermiticity 与曲率虚部泄漏（均为约 \(10^{-14}\)–\(10^{-16}\) 数量级），但尚未替代 symmetry-closed 参考解。K 点单点信号也不代表整个 Brillouin 区。

这里不能预先承诺非零 Chern 数；本次探针已经观察到 rank-2 总曲率迹在当前对称设置下抵消。局部探针支持把量子度量列为优先下游量，但正式 reference 尚未通过；Wilson-loop 谱仍需另行验证。

## 8. 下一轮实验的 GO / STOP 标准

### P3 小型 pilot

- harmonic + localized Gaussian 两势族；
- 3 个共享新 seed；
- exact / near / IID / strict OOD；
- anchor-only、当前 dual-path、OMM/block baseline、P3；
- 500–1000 steps，冻结同一训练预算；
- RTX 5090 暂估 2–4 GPU h、RTX 4090 暂估 3–6 GPU h、RTX 4060 暂估 6–12 GPU h；三者都必须以各自首个校准 run 更新，不能把 4090/5090 GPU 小时混写成实测等价量。

### GO

- 两势族均 3/3 seed 无失败、无 NaN；
- \(\|Q^*MQ-I\|_F<10^{-5}\)；
- 相对 anchor-only 至少改善 20%；
- 相对最强无标签 block baseline 两势族均至少改善 15%；
- 两势族 near-cluster projector error 的绝对门槛预注册为均值 <0.08，理想目标 <0.05；否则两个差模型之间的相对改善不足以支持论文；
- near 与 strict OOD 均同方向改善；
- 训练时间不超过最强基线约 2 倍；
- 置信评价预注册 Spearman \(\rho\)、Kendall \(\tau\)、AU-risk–coverage、coverage@固定风险阈值与 bootstrap 95% CI；不使用“趋势明显”作为成功标准；
- 同时报告等 steps、等 wall-clock、参数量、峰值显存，以及触发 PWE/迭代 fallback 后的总成本。

### STOP / 回炉

- 只在 harmonic 有效；
- Gaussian 持平或变差；
- 优势仅来自更多参数、训练步数或采样点；
- 3 seed 方向不一致；
- 把 fallback 成本计入后，25-mode PWE 在目标 many-query 区间仍全面更准、更快；
- projector 物理量对网格/步长极不稳定；
- chart 切换频繁但没有带来误差/风险覆盖改善。

### 最安全的贡献表述

> We develop a label-free neural correction framework for parameterized Bloch spectral clusters. A symmetry-preserving low-order Bloch subspace defines a local metric Grassmann chart, while a coordinate network learns only the orthogonal-complement correction. External spectral gaps and chart geometry are used to route multiple charts, calibrate failure risk, and trigger numerical fallback at internally degenerate points.
