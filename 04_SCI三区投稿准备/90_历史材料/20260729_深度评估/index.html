使用的神经网络

Dual-path anchored
Ky Fan coordinate network

SiLU MLP 接收周期坐标、Bloch 波矢与势参数，输出两个复值周期场。正式候选为 4 层、宽度 96/128；本次 MPS smoke 使用 3×48 小网络。网络通过 Ky Fan 变分目标训练，不使用本征子空间标签；主输出不是两条被强行编号的能带，而是基底不变 projector。

(s, k, ξ) → coordinate MLP → orthonormal frame Qθ → Pθ = QθQθ*

准确归类：label-free parametric coordinate neural variational eigensolver。它属于真实神经 PDE 本征求解，但不是普通点态 residual PINN。

Problem formulation

这确实是神经网络解 PDE

网络直接表示二维周期场，损失由微分算子与变分原理给出。Fourier/PWE 只用于冻结测试的参考解与低保真 anchor，不是训练标签。

01 / INPUT

坐标与参数

周期坐标 s=(s₁,s₂)、Bloch 波矢 k，以及 harmonic 或 Gaussian honeycomb 势参数 ξ。

02 / NETWORK

坐标神经场

周期特征编码 + 4 层、96/128 宽 SiLU MLP，输出两个复值 correction 场的实部与虚部。

03 / OUTPUT

谱投影而非带标签

P₂=Σj=12ujuj*。簇内任意 U(2) 旋转给出同一 rank-2 不变谱子空间的等价本征基。

低阶物理 anchor当前为固定 3-wave；参数化 3/9-wave 属 P3 待实现
神经 correction学习 anchor 漏掉的分量
dual-path / Grassmann保持 θ 梯度，隔离空间导数
Ky Fan trace无标签最小化低能谱簇
projector + Ritz readout同秩只读出能量；须以 m=3/4>r=2 冗余子空间选最低 2 维，才可能校正投影

真正的研究问题：当两条能带在 K 点无法稳定编号时，能否让一张无标签网络学习仍然连续、良定的 rank-2 谱簇？

P3.1 / METRIC CHART

参数 ROM + 质量度量

对称闭合 3/9-wave A(μ)；若 A*MA=I，先令 Z=(I−AA*M)N，再做 Q=(A+Z)(I+Z*MZ)−1/2；不能使用欧氏投影 (I−AA*)N，主角也必须 M-weighted。

P3.2 / ROUTING

多图册 Grassmann

用 3-wave、9-wave 或邻域 chart；最大主角接近 90° 时路由切换，而非强行外推单 chart。

P3.3 / CONFIDENCE

可计算风险与 fallback

常规推理只用 block residual、低阶 PWE/ROM gap surrogate、chart angle 与 chart disagreement；高风险样本转冗余 trial-subspace 局部校正或高 cutoff PWE。真 ΔKF 与高 cutoff gap 只做离线校准。

A*MA=I，Z=(I−AA*M)N，Q=(A+Z)(I+Z*MZ)−1/2，P=QQ*M

ŝ 是风险估计，不是数学证书。 ΔKF=Tr(Q*HQ)−Σλi 与真实外部 gap 需要参考本征值，只能用于离线校准/理论图，不能冒充无标签在线分数。核心验证线：M-度量正交与 basis invariance；chart 覆盖和失败边界；risk–coverage 校准；33/65/129（必要时 257）网格一致性；神经 projector 对量子度量的误差与稳定性。
