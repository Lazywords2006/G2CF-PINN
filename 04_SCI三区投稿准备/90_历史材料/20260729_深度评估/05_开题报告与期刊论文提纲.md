# 开题报告与期刊论文提纲

## 一、暂定题目

中文：

> 面向内部简并 Bloch 谱簇的无标签间隙感知多图册 Grassmann 神经校正方法

英文：

> Label-Free Gap-Aware Multi-Chart Grassmann Correction for Internally Degenerate Bloch–Schrödinger Spectral Clusters

保守版本题目：

> A Label-Free Neural Variational Solver for Rank-Two Bloch Spectral Clusters

建议方法名在完整 ROM-Grassmann 原型通过两势族 pilot 后再冻结，当前不要频繁创造缩写。

## 二、研究背景

神经 PDE 求解通常把未知温度、速度或位移场表示为网络，并最小化点态 residual 或变分能量。本课题研究另一类真实 PDE：参数化椭圆微分算子的本征谱。

周期材料、量子晶格和光子/声子结构中的 Bloch 本征函数只在相位和简并簇内旋转意义下确定。当最低两条能带在 K 点相交时，分别学习“第一带”和“第二带”会引入人为标签不连续；真正稳定的对象是它们共同张成的 rank-2 谱子空间或 projector。

现有工作已经覆盖 trace 多本征求解、神经子空间、参数化本征问题、mode switching、无标签 Bloch 网络和 honeycomb Dirac 点。2026 年新增的 Boundary-aware Neural Model Reduction、NEO、ICLR Subspace Regression、Hybrid FNO 与 vRBA 又分别覆盖了参数族无标签 eigenanalysis、mass-aware eigenspace、Grassmann 回归、跨分辨率 band surrogate 与残差自适应。因而以下条件必须作为一个完整联合机制成立，任何单一组件都不能宣称首创：

- 无 eigenspace 标签；
- 一张网络跨 Bloch 与势参数；
- 二维 Bloch–Schrödinger PDE；
- 内部精确简并；
- 固定秩、基底不变 projector；
- Ky Fan 目标；
- 参数相关物理低保真 anchor 与 metric Grassmann correction；
- 外部 gap 与 chart angle 驱动的 multi-chart routing、risk calibration 和数值 fallback。

## 三、研究问题

### 核心问题

对于具有内部简并但与其余谱保持外部 gap 的二维 Bloch–Schrödinger 参数族，能否在不使用参考 eigenspace 标签的情况下，用一张坐标神经网络稳定学习最低 rank-2 spectral projector？

### 子问题

1. projector-first 表示是否比逐带排序在 crossing 附近更连续、更可训练？
2. 物理低保真 anchor 的贡献能否与网络 correction 分离？
3. dual-path/Grassmann retraction 是否修复离散正交与空间自动微分之间的冲突？
4. 参数相关 3/9-wave ROM anchor 是否比固定 K 点 anchor 提升 Gaussian 与 OOD 泛化？
5. block residual、低阶 ROM gap surrogate、M-主角与 chart disagreement 能否形成可计算且可校准的风险指标？真 Ky Fan excess 与真外部 gap 只用于冻结测试和离线分析。
6. 与 9/25-mode PWE、Wang–Xie、Dai、OMM、Rowan 和监督 Grassmann 相比，网络在哪个精度–成本区间有价值？

## 四、PDE 问题定义

在周期单胞 \(\Omega=[0,2\pi)^2\) 上，求

\[
H_\mu u_j=\lambda_j u_j,
\quad
H_\mu=\frac12(-i\nabla+k)^\top G(-i\nabla+k)+V(s;\xi),
\quad \mu=(k,\xi).
\]

周期边界：

\[
u_j(s+2\pi e_\ell)=u_j(s),\qquad
\nabla u_j(s+2\pi e_\ell)=\nabla u_j(s).
\]

假设目标簇与第三本征值隔离：

\[
g_{ext}(\mu)=\lambda_3(\mu)-\lambda_2(\mu)\ge\gamma_0>0,
\]

但允许

\[
g_{int}(\mu)=\lambda_2(\mu)-\lambda_1(\mu)=0.
\]

目标输出为

\[
P_\star(\mu)=U_\star(\mu)U_\star(\mu)^*,
\quad U_\star^*U_\star=I_2.
\]

## 五、网络输入与输出

### 输入

- 空间坐标 \(s=(s_1,s_2)\)；
- Bloch 波矢 \(k=(k_1,k_2)\)；
- harmonic 势：\((V_0,\delta)\)；
- Gaussian 势：\((A,\sigma,\eta)\)。

### 输出

两个复值周期场的实虚部：

\[
N_\theta(s,\mu)\in\mathbb R^{2\times2}.
\]

网络建议：4 层、每层 96 或 128 个神经元、SiLU；空间使用 \(\sin s_1,\cos s_1,\sin s_2,\cos s_2\) 周期编码。正式结果按参数量公平匹配。

## 六、拟提出的方法

### 1. 参数相关低保真子空间

从 3-wave 或 9-wave 小型 Bloch Hamiltonian 得到 rank-2 anchor \(A(\mu)\)。该 anchor 是方程内生的低保真近似，不是 ground-truth 标签。

### 2. Grassmann graph correction

设 \(A^*MA=I\)，网络 correction 投影到质量矩阵定义的正交补：

\[
Z_\theta=(I-A A^*M)N_\theta.
\]

用 graph/polar retraction：

\[
Q_\theta=(A+Z_\theta)(I+Z_\theta^*MZ_\theta)^{-1/2}.
\]

它自动满足 \(Q_\theta^*MQ_\theta=I\)，不需要经验性的 \(\alpha<1/2\)。主角与 chart 距离也采用相同的 \(M\)-加权内积。

### 3. dual-path quadrature transform

在 `coordinates.detach()` 的共享权重第二前向上计算 Gram、projection 和 inverse-square-root，使这些全局变换：

- 对网络参数可微；
- 对点态空间导数视为常量；
- 不把一个查询点的空间导数耦合到其他网格点。

### 4. 无标签 Ky Fan 目标

\[
\mathcal L_{KF}(\theta)
=\mathbb E_{\mu}\operatorname{Tr}
\langle Q_\theta,H_\mu Q_\theta\rangle.
\]

不使用 PWE/FEM eigenspace labels。参考解只在冻结测试阶段使用。

### 5. 可计算的 gap–chart 风险诊断

用 block residual、低阶 ROM gap surrogate、M-主角和多 chart disagreement 形成 risk estimator，用于：

- 报告失败风险；
- 选择 multi-chart anchor；
- 不确定参数的重点采样；
- 不能保证时主动触发 PWE fallback。

真实 Ky Fan excess 依赖真低阶本征值和，真实外部 gap 依赖第三本征值，因此只在冻结测试与离线校准中使用；训练时不得调用高 cutoff eigensolver 充当隐性标签。该 risk estimator 不称严格 certificate。

### 6. 冗余 trial subspace 与 Ritz

候选网络输出 \(m=3\) 或 4 维 trial subspace，再通过小型 generalized Ritz solve 保留最低 \(r=2\) 维。只有 \(m>r\) 时这一步才可能改变目标 projector；若 \(m=r=2\)，它只能称 Ritz readout，不能称 projector correction。

## 七、理论工作

计划给出以下命题。

### 命题 1：基不变性

对任意 \(R\in U(2)\)，projector、Ky Fan trace、无序 Ritz spectrum 和主角指标在 \(Q\mapsto QR\) 下不变。

### 命题 2：Grassmann graph 正交性与覆盖

证明 graph retraction 的精确正交性，并说明当目标子空间与 anchor 的最大主角小于 90° 时，目标位于该 chart。

### 命题 3：固定参数的 gap bound

在算子二次型域内：

\[
e_P(\mu)^2
\le
\frac{\Delta_{KF}(\mu)}{r\,g_{ext}(\mu)}
=\frac{\overline\Delta_{KF}(\mu)}{g_{ext}(\mu)},
\qquad
e_P=\frac{\|P_\theta-P_\star\|_F}{\sqrt{2r}}.
\]

### 命题 4：参数平均版本

若 \(g_{ext}\ge\gamma_0\)：

\[
\mathbb E_\mu[e_P^2]
\le
\frac{\mathcal L_{KF}(\theta)-\mathcal L_\star}{r\gamma_0}
+\text{approximation error}
+\text{quadrature error}.
\]

### 命题 5：离散化误差

给出离散 Gram、离散能量与连续内积之间的误差项；配合 33/65/129 网格实证。

理论引用必须包括 Ky Fan 1949、Davis–Kahan 1970、Grubišić et al. 2023、Dölz & Ebert 2024 和 trace generalization 2023。

## 八、预期创新

### 核心创新候选

参数相关低保真 Bloch 谱簇作为 Grassmann chart，神经网络只学习正交补 correction；配合 dual-path retraction 在保持正确参数梯度的同时避免空间自动微分污染。

创新强度预判：**中等，前提是两势族和强 block baseline 上成立。**

### 次要创新候选

- 基于可计算 ROM gap surrogate、block residual、M-chart validity 和 disagreement 的风险/失败诊断；
- multi-chart anchor 与 PWE fallback；
- projector quantum metric 的局部可行性与后续神经误差评价；
- 针对内部简并 Bloch cluster 的 640 点基准协议。

这些内容不能只停留在模块组合，必须有定理、消融或失败边界。

## 九、实验假设

H1：dual-path/Grassmann 版本在两势族上相对 stop-gradient 至少改善 15%。  
H2：ROM-Grassmann 相对 anchor-only 至少改善 20%。  
H3：相对最强无标签 block baseline，两势族 near split 都改善至少 15%。  
H4：projector error 与 \(\overline\Delta_{KF}/g_{ext}\) 显著相关并满足离散修正界。  
H5：两势族 near split 的绝对 projector error 均值低于 0.08；置信评价按 Spearman/Kendall、AU-risk–coverage、固定风险阈值 coverage 与 bootstrap 95% CI 预注册。  
H5：网络不会普遍击败 25-mode PWE 的绝对精度，但可在更高参考精度或大批量参数查询下形成合理 Pareto 位置。

H5 必须允许被否证；不能预设网络一定更快。

## 十三、风险与应对

| 风险 | 发生时的处理 |
|---|---|
| ROM/PWE 始终更准更快 | 把论文定位为 uncertainty-aware amortized cluster map；若无 break-even 则停止效率主张 |
| Gaussian 不改善 | 不能投“通用方法”；回到参数相关 anchor/multi-chart，不扩正式矩阵 |
| OMM/Wang–Xie 持平 | 说明新机制创新不足；停止 SCI 三区主张 |
| 单 chart 失效 | 用 principal angle 触发 multi-chart/fallback |
| gap 关闭 | 明确方法只针对 isolated cluster，报告失败边界 |
| 理论与离散实现不一致 | 给出离散命题和 quadrature term，不用连续定理替代代码证明 |
| 结果依赖更多预算 | 统一 steps/FLOPs/参数量并做 time-matched 对照 |
