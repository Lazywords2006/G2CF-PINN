# 正式实验设计、算力预算、成功线与发表图表

## 1. 实验目标

正式实验必须回答四个不同问题：

1. **表示问题**：固定秩 projector 是否比逐带排序在内部简并附近稳定？
2. **优化问题**：dual-path / Grassmann retraction 是否比错误的 stop-gradient MGS 稳定且准确？
3. **先验问题**：改进来自神经 correction，还是几乎全部来自正确 anchor？
4. **实用问题**：面对低阶 PWE、ROM 和强无标签神经子空间方法，网络在哪个 many-query 场景有价值？

任何一个问题都不能只用一张总误差表回答。

## 3. 参数域与冻结测试

### 势族 1：harmonic honeycomb

\[
V(s)=V_0[\cos s_1+\cos s_2+\cos(s_1-s_2)]
+\delta[\sin s_1-\sin s_2-\sin(s_1-s_2)].
\]

训练盒：

\[
k_1,k_2\in[0.28,0.38],\quad
V_0\in[0.2,0.8],\quad
\delta\in[-0.08,0.08].
\]

### 势族 2：periodic two-sublattice Gaussian honeycomb

训练盒：

\[
k_1,k_2\in[0.28,0.38],\quad
A\in[1,4],\quad
\sigma\in[0.18,0.35],\quad
\eta\in[-0.08,0.08].
\]

### 每个势族 320 个冻结点

| Split | 数量 | 定义 |
|---|---:|---|
| IID hidden | 96 | 训练盒内 LHS，全新 seed |
| exact cluster | 32 | K 点、对称破缺为 0、参考 \(g_{int}\) 在离散容差内为 0 |
| near cluster | 64 | 由参考 PWE 筛选 \(0<g_{int}\le0.01\)，且 \(g_{ext}\ge0.05\) |
| strict OOD | 64 | 至少一维超出训练盒 10%–20%，不是扩大盒随机抽样 |
| gap scan | 64 | 覆盖不同 \(g_{ext}\)，用于失败边界和理论图 |

总测试点：`2 × 320 = 640`。validation 另行生成，final test 不参与 smoke 和超参数选择。

## 4. 共同预算与可复现性

- 主网络宽度/深度和参数量同数量级；
- 相同 optimizer、训练 steps、parameter batch、空间点数；
- 参数/坐标流由预生成的 common RNG stream 提供，与模型初始化 RNG 分离；
- final test 只在方法和超参数冻结后运行一次；
- 主比较 10 个 seed；完整长尾消融至少 3 个 seed；
- 所有 run 使用不可变 `run_id`，非空目录拒绝写入；
- checkpoint 保存 CPU/CUDA/MPS RNG 状态、optimizer、scheduler、config hash、git diff hash；
- 每个 CSV 行保存 `suite_hash`, `checkpoint_hash`, `rng_stream_hash`；
- 失败 run 也保留日志，不静默删除。

## 5. 参考解标准

1. PWE 模态集合使用 K-centered kinetic shell 或 honeycomb little-group 轨道闭包，不能用简单方形 `[-c,c]^2` 宣称精确简并；
2. harmonic 与 Gaussian 都做 cutoff 8/12/16；
3. 对每个 split 报告 cutoff 12 对 16 的 projector、Ritz 和 gap 差；
4. 正式主参考只有在 projector 差 < `1e-3` 或低于主方法误差至少两个数量级时才接受；
5. Gaussian 坐标势与解析 Fourier 系数已有单参数、单模态自动测试，当前可追踪门槛为误差 `<1e-10`；正式稿仍需保存多参数、多模态实测 JSON；
6. exact K 的有限截断伪劈裂必须单独报告，不能隐去。

## 6. 主要评价指标

### Primary endpoint

near-cluster split 的 projector sine error：

\[
e_P=\frac{\|\widehat P-P_\star\|_F}{\sqrt{2r}},
\qquad r=2.
\]

因此本项目 rank-2 数值实际是 \(\|\widehat P-P_\star\|_F/2\)。定义 true Ky Fan excess

\[
\Delta_{KF}=\operatorname{Tr}(Q^*HQ)-\sum_{j=1}^{r}\lambda_j,
\qquad \overline\Delta_{KF}=\Delta_{KF}/r,
\]

则固定参数、外部谱隙成立时使用 \(e_P^2\le\Delta_{KF}/(r g_{ext})=\overline\Delta_{KF}/g_{ext}\)。这与当前代码指标和 true-trace 目标一致。

### Secondary endpoints

- 最大和 RMS principal angle；
- signed normalized Ky Fan excess；
- \(\overline\Delta_{KF}/g_{ext}\)；
- 两个无序 Ritz eigenvalue 的相对误差；
- internal band gap 误差；
- block residual Hilbert–Schmidt norm；
- orthogonality error；
- periodic boundary value/derivative error；
- wrong-cluster rate；
- 平均、标准差、中位数、p95、最大值；
- 参数量、训练时间、推理时间、峰值显存、FLOPs；
- 训练摊销后的 break-even 查询数。

精确简并处不以未对齐单个 eigenfunction MAE 作为主指标。若展示单模态，先进行 complex Procrustes alignment，并注明仅用于可视化。

## 7. 统计方案

1. 以相同 `seed + point_id` 形成真实配对；
2. 主表同时报告 seed-level aggregate 和逐点分布；
3. 用嵌套 bootstrap（先 seed、再 point）给出 95% CI；
4. 对 seed-level 配对差使用 exact permutation/Wilcoxon，报告真正 matched-pairs rank-biserial；
5. 多方法比较使用标准 Holm step-down，首次不能拒绝后停止；
6. 同时报告绝对差、相对差和最小有意义效应，不只报 p-value；
7. supervised 上界和传统 PWE 不混入“无标签方法显著胜出”的同一假设族。

## 8. 论文成功线

### 最低 SCI 四区门槛

- 两势族均完成；
- P1/P2 相对 anchor-only 至少改善 20%；
- 相对至少一个强无标签 block/subspace baseline 有稳定改善；
- 10 个主 seed 中至少 8 个同方向；
- 95% CI 不跨 0；
- near 和 OOD 都有改善；
- 正交、边界和参考收敛全部合格；
- 不声称优于 PWE，除非公平计时支持。

### SCI 三区目标

- P3 在 harmonic 和 Gaussian 都相对最强无标签神经基线改善 15%–20%；
- near-cluster 平均 projector error 建议 < `0.08`，更理想 < `0.05`；
- OOD 提升不是以 IID 明显退化为代价；
- 参数相关 ROM anchor、Grassmann correction 和 gap-aware 模块均有独立消融；
- 理论界散点和 grid/cutoff 收敛支持主张；
- 相对 25-mode PWE 有明确的精度–成本位置和 many-query 使用场景；
- 第二算子或至少第二势族排除“只适配三波 harmonic”的解释。

## 9. 需要的算力与环境

### 当前设备

| 设备 | 用途 | 结论 |
|---|---|---|
| MacBook Air M4 / MPS | 开发、单元测试、300–500 step smoke、画图 | 已验证可用，不作为正式性能结果 |
| RTX 4060 8GB | 3-seed pilot、部分正式训练 | 显存足够；完整矩阵预计较慢 |
| RTX 4090 24GB | 主正式实验 | 推荐性价比档 |
| RTX 5090 32GB | 更快的正式矩阵和 PWE batch | 可用但非必需；模型显存需求很小 |
| A100 40/80GB | float64 与高 cutoff 最终复核 | 仅按需短租，不建议全程使用 |

当前历史 RTX 4090 实测：

- 旧 5,000-step anchored 模型约 169–172 秒/seed；
- no-anchor 约 221–223 秒/seed；
- ordered baseline 约 372–379 秒/seed；
- anchored 峰值显存约 486 MB；慢基线约 1.6–2.1 GB。

dual-path 的 MPS 烟测时间为旧 MGS 的 1.35×。据此做规划估计：

| 阶段 | RTX 4090/5090 | RTX 4060 | 说明 |
|---|---:|---:|---|
| 2 势族 × 3 seed 小 pilot | 2–4 GPU h | 6–12 h | 先决策，不跑满矩阵 |
| 主方法/强基线 10 seed | 8–16 GPU h | 24–48 h | 取决于慢基线 |
| 消融、泛化、敏感性 | 6–12 GPU h | 18–36 h | 至少 3 seed |
| 高 cutoff / float64 审计 | 2–6 GPU h | 8–20 h | 可短租 A100 |
| 总规划 | **18–38 GPU h** | **约 2–4 天** | 不是承诺计时，需以 pilot 校准 |

存储建议：40–80 GB；包括 checkpoint、640 点参考缓存、CSV、日志、图和环境清单。CPU 12 核足够，参考矩阵装配和数据加载可使用 8–12 核。

### 软件

- Python 3.11/3.12；
- PyTorch 2.8 或冻结的 CUDA 兼容版本；
- CUDA 12.x 镜像即可，不需要 CUDA 13 特性；
- NumPy、SciPy、pandas、matplotlib、seaborn；
- 可选：torch.func、functorch/vmap 用于 batched PWE/参数梯度；
- 保存 `pip freeze`, `nvidia-smi`, GPU 名称、driver、CUDA、cuDNN、OS 和 commit/diff hash。
