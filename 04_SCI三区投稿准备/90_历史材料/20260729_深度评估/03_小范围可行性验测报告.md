# 小范围可行性验测报告

## 1. 验测问题

这次不是试图证明论文已经成立，而是回答三个更窄的问题：

1. 修复后的 V2 参数协议能否真正区分 IID、精确简并、近简并和严格 OOD？
2. 旧 `periodic_mgs` 的 stop-gradient 是否是实质问题？
3. 用 dual-path MGS 修正网络参数梯度后，是否值得继续进行 CUDA pilot？

用于解释本次验测的宽工程 GO/STOP 条件（不是正式统计预注册；精确重建阈值为结果后锁定）：

- V2 protocol 必须无训练盒重叠，near 点必须由参考内部 gap 证实；
- 3/3 seed 无 NaN；
- orthogonality error < `1e-5`；
- dual-path 相对旧版明显改善，成本 < 2×；
- 若只在一个手选 K 点改善，则不判 GO。

## 3. dual-path MGS 原理

旧版 MGS 在前向中得到正交 frame，但对全局投影系数和 norm 使用 `detach()`：

\[
q_1=\frac{v_1}{\|v_1\|},\qquad
q_2=\frac{v_2-q_1\langle q_1,v_2\rangle}
{\|v_2-q_1\langle q_1,v_2\rangle\|}.
\]

detach 同时切断：

- 不希望出现的“Gram 系数对坐标点移动的导数”；
- 本应保留的“Gram 系数对网络参数的导数”。

20 个随机参数方向的旧版 autograd/有限差分诊断，中位相对误差约 27.3%，最坏案例甚至符号相反。

dual-path 方案执行两次共享权重前向：

- `raw = f_theta(x, mu)`，保留空间导数；
- `normalization_raw = f_theta(stopgrad(x), mu)`，用于 Gram/归一化变换。

因此 Gram 变换仍对 \(\theta\) 可微，但对当前空间坐标变量为常量。新增单元测试验证：

- dual-path frame 的复 Gram 等于单位阵；
- 参数方向 autograd 与中心有限差分在 `rtol=2e-4` 内一致；
- 一个点的输出对其他查询点坐标的导数严格为零。

## 6. 结果判定

### 明显有效

- dual-path 在 3/3 seed 和 36/36 点—seed 对比中改善；
- 提升同时存在于 IID、exact、near 和 OOD；
- 额外成本 35%，低于 2× 门槛；
- 正交性和数值稳定性未恶化。

### 尚不足以支持

- 不能说明双分支网络已经达到期刊 SOTA；
- 不能说明比 25-mode PWE 更准或更快；
- 不能说明 Gaussian 上也有效；
- 不能说明超过 Wang–Xie、Dai 或 OMM 式强无标签 block baseline；
- n=3、12 点、300 steps，不进行期刊级显著性推断。

## 7. 最终门槛

本次结论：`SMOKE_GATE_PASS_NOT_PAPER_RESULT`。

允许进入下一个 3-seed CUDA pilot，但禁止直接跳到完整 10-seed 正式矩阵。下一 pilot 必须加入 Gaussian、共同训练流、低阶 PWE、无 anchor block/OMM 和 ROM-Grassmann 候选。
