# 代码、实验协议与可复现性状态

更新：2026-07-29

## 结论

当前代码已经达到“可以做新的 V2 CUDA 小 pilot”的工程条件，但**没有**达到“可以直接跑 10-seed formal”的科学协议条件。旧 V1 入口已硬阻断，避免误续训或误把旧结果升级为投稿证据。

## 已验证

- `45/45` 自动测试通过；
- dual-path 复 MGS 的参数梯度与有限差分一致；
- 含二阶 Bloch Hamiltonian 的模型级梯度回归通过；
- frame 复 Gram、周期边界和坐标局部性测试通过；
- Ky Fan 实现已从 rank mean 改为 true trace；
- 最新源码下 CPU 10-step true-trace dual-path V2 工程烟测完整运行；
- checkpoint 保存配置、SHA-256 可重算指纹、seed、CPU/CUDA/MPS RNG、optimizer、训练行和 elapsed time；
- 参数与坐标使用独立 CPU sampling generator，不受模型初始化、架构参数量或 accelerator RNG 消耗影响；
- resume 配置或 seed 不一致时拒绝继续；
- evaluator 校验 checkpoint 内嵌语义配置、当前协议源码指纹并记录 checkpoint SHA-256；
- evaluator 将参考解缓存绑定到 suite ID/SHA-256、PWE cutoff、评估网格、点 ID、完整张量形状与有限值，拒绝静默复用错误缓存；
- 已完成 checkpoint 若缺失 `run_summary.json`，会进入只评估/原子收尾路径，而不是把不完整运行误判为完成；
- suite 声明点数、唯一 ID、family/split、参数有限性均校验；
- paired statistics 要求完全相同的 seed 集和逐 seed point ID 集；
- smoke decision builder 要求完整预期 suite、完整 config seed、逐 seed 训练/评价 checkpoint SHA 与 config/source fingerprint 绑定，并要求两臂仅允许正交化/名称/输出目录不同；旧归档只有显式 legacy-unbound 模式可重建，不能用于新 pilot；
- Holm 使用合法的 step-down 停止规则；
- CUDA 每 seed 重置 peak memory；MPS 只报告 current memory，不再伪称 peak。

1. 在正式 CUDA pilot 前导出并封存 sampling stream hash；代码已保证不同模型容量下同 seed 使用相同 stream；

3. validation/final 严格分离的 640 点正式 V2 suite；

5. harmonic 与 Gaussian 两势族共享 seed 的 CUDA pilot；

7. 主实验前冻结成功线、统计假设与 figure manifest。
