# 下一阶段实验计划：风险可检测性与条件谱簇校正

## 研究假设

旧假设“无条件增加低频 ROM 会稳定改善谱簇预测”已经被 P5 否定。新的可证伪假设是：

> 可以仅依靠推理时可获得的 PDE 与网络量，识别 anchor/ROM 在参数域中的失效风险；在
> 风险可校准时进行条件局部校正，在高风险时回退 PWE，从而同时改善 near-cluster 精度
> 和 gap-scan 安全性。

这只是待验证假设。若风险排序接近随机，立即 STOP，不继续实现复杂路由。

## 阶段 A：离线风险可检测性

### 数据

- 保留 P5 validation 只作回顾分析；
- 新建与 frozen final 隔离的 risk-development suite；
- 两个势族各至少覆盖 IID、exact、near、strict-OOD、gap-scan；
- 点 ID、参数、参考 cutoff、seed 和 SHA-256 在训练前冻结。

### 特征

必须是推理时无需真值 projector 即可计算的量：

1. PDE residual RMS 与 projected residual；
2. Gram condition、正交误差和 generalized-trace 数值稳定性；
3. 预测 Ritz 值与 trial-space 第三方向形成的外部间隔代理；
4. 多 chart / 多视图 projector disagreement；
5. anchor 与校正分支的夹角、修正幅度和局部敏感度；
6. 小型 ensemble 或 checkpoint disagreement（若成本允许）。

### 指标

- AUROC、AUPRC；
- top-k failure precision / recall；
- risk–coverage 与 selective error；
- 两势族分别报告，不只报告合并均值；
- bootstrap 95% CI。

### 阶段 A 成功线

- AUROC 建议至少 `0.70`，且 95% CI 下界明显高于 `0.50`；
- AUPRC 明显高于失败率基线；
- 在两个势族和 gap-scan 都有方向一致的排序能力；
- 特征不读取真值 projector 或参考外部谱隙。

## 阶段 B：条件校正小测

### 方法

- anchor 网络作为默认输出；
- 风险低且校正经开发集证明可靠时启用局部谱簇校正；
- 风险高或不确定时回退 PWE；
- 路由阈值只用 risk-development suite 冻结，不能在 final 上调整。

### 公平基线

1. `p5_anchor`；
2. `p5_long_anchor`；
3. `p5_static_low_rom`；
4. 参数量匹配 wide-anchor；
5. trace/Ky Fan 神经子空间基线；
6. 传统 PWE。

### 最小矩阵

- 2 个势族 × 3 seeds；
- 相同训练点、参考缓存和 seed；
- 参数量与 wall-clock 两种公平口径；
- 先用 RTX 4060 或 MPS 做 5–50 step 工程 smoke；
- 工程通过后单张 4090/5090 运行 500–1000 step 决策 pilot。

### 阶段 B 成功线

- near-cluster 相对 long-anchor 至少改善 5%；
- gap-scan 不超过最佳非 ROM 基线 2%；
- 每个势族均改善，至少 5/6 势族×seed 配对获胜；
- 回退率、推理时间和 many-query break-even 可接受；
- 正交、Gram、有限性与 evidence manifest 全部通过。

## 阶段 C：只有 GO 后才做

- 冻结下一 promotion 协议；
- 补强 Wang–Xie、Dai/trace、ordered、supervised Grassmann 等基线；
- 消融风险特征、局部校正与 fallback；
- 训练点、噪声、分辨率、参数外推、效率和量子度量；
- 最后只运行一次 frozen final。
